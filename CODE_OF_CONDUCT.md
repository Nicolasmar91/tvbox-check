# Code de conduite

Ce projet est un espace de travail factuel et bienveillant.

- **Parlez de faits, pas de personnes.** Décrivez ce qui a été observé, avec les preuves. Pas d'insulte, pas d'accusation envers un vendeur, une marque ou un contributeur.
- **Critiquez le travail, pas la personne.** Une relecture sévère reste respectueuse.
- **Accueillez les débutants.** Une première PR de données est une vraie contribution.
- **Respectez la vie privée.** Ne publiez ni données personnelles ni informations d'autrui.
- **Pas de spam, de publicité ni de harcèlement.**

Le mainteneur peut modérer, fermer un échange ou refuser une contribution qui ne respecte pas ces règles. Pour signaler un problème : nicolasmar91@gmail.com.
